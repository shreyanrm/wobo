**Domain:** application security (OWASP Top 10 2021, OWASP API Security Top 10 2023, OWASP ASVS 4.0
Level 2 controls for authentication, session management, access control, input validation and error
handling).
**Product under review:** Wobo — a direct-to-family web product used by children.

**Date of the sweep:** 2026-09-04.

## How to read this

Every item carries exactly one status:

| Status | Means |
| --- | --- |
| **MET** | Verified against real code or a command whose output is quoted. |
| **PARTIAL** | Something real exists; something real is missing. Both are located. |
| **NOT MET** | The control does not exist. |
| **N/A** | Considered and does not apply to this product. The reason is given. |
| **NOT VERIFIED** | Needs a live credential, a running service, a third-party console or a human. What would verify it is named. |

Nothing here is ticked without evidence. Where the evidence is a command, the command and its real
output are given. This register describes the code as it stands; it is **not** a penetration test, an
audit, or a certification, and nothing in it should be quoted as one.

## Section 0 — Route inventory: where does the learner identity come from?

The task says enumerate, do not sample. Below is **every** route the gateway registers
(`grep -rn "@app\.\(get\|post\|put\|delete\|patch\|websocket\)" services/gateway/src/` — 30 route
declarations across 7 modules). "Identity source" is the only column that matters for BOLA: an
identity taken from the request is a finding, an identity derived by the server is not.

The single door is `services/gateway/src/wobo_gateway/app.py:669-761` — one HTTP middleware that
calls `authenticate(request.headers)` (`app.py:687`) for every path starting `/v1` that is not in
`_OPEN_PATHS` (`app.py:387`) and is not `OPTIONS`. It stores the result on `request.state.principal`
(`app.py:691`), the mirror `request.state.subject` (`app.py:693`) and the derived
`request.state.meter_key` (`app.py:696`).

**Verdict on the inventory:** no route reads a learner identity out of a request body or query
string. Two fields that used to do so are accepted-and-ignored on purpose and documented as such:
`CapabilityRequest.consent_tier` (`app.py:179-185`) and `EmailSendRequest.consent_tier`
(`email.py:493-497`). The engine slot key and the meter key both come from the door
(`plexus/engines.py:1859-1874`, `app.py:444-458`).

The one soft spot is the **anonymous** meter key, which is the device address rather than the
subject. Demonstrated:

```
$ uv run python -c 'meter_key(Principal("anon-alice", anonymous=True), req) ...'
alice: anon:203.0.113.9
bob  : anon:203.0.113.9
same board/budget bucket: True
```

Two different anonymous learners behind one NAT therefore share a board-turn namespace
(`app.py:454-458` + `board/stream.py:119-128`) and one day's allowance. See item 4.3.

## Section 9 — The gaps that would actually hurt, worst first

1. **No spend ceiling anywhere (2.21).** `record_cost` computes the dollar cost of every model call
   and then only writes a log line (`telemetry.py:59-97`). Per-learner call counts are capped, but
   nothing caps the platform's day. For a free-tier product with anonymous sign-in in front of
   frontier models, this is the denial-of-wallet hole, and it is one accumulator away from closed.
2. **Nobody is alerted about anything (6.14).** No Sentry, no metric exporter, no alert rule, no
   on-call route. Every other control in this register fails silently. This is the cheapest fix here
   and it multiplies the value of everything else.
3. **The request body cap can be walked past (2.16).** Verified: a 400 KB chunked body sailed through
   a 256 KB ceiling and was served. `Content-Length` is a client-supplied header; the cap has to be
   enforced while reading the stream.
4. **Known-vulnerable `aiohttp` in the runtime path (1.34)**, plus 17 JS advisories in the build path
   (1.33), and **nothing in CI checks either (1.35)**. `aiohttp` carries the live voice relay.
5. **The gateway's HTML pages ship with no security headers (1.26, 1.7).** The parent-facing
   opt-out and invite pages are frameable, sniffable and served without HSTS. Verified live.
6. **OAuth uses the implicit flow, and the refresh token lands in `localStorage` (3.6, 3.5).** PKCE
   is the fix the SDK's own comments already anticipate.
7. **The JWT issuer is never checked (2.7).** Cheap to add, and it is the difference between "a token
   from our project" and "a token signed with a secret that happens to match".
8. **Anonymous learners share an identity namespace by IP address (2.2).** Two children on one
   school network can reach each other's board turn. A deliberate anti-abuse trade with an
   unintended privacy edge.
9. **Every limit is an in-process dict (1.23).** Correct today at `numReplicas: 1`; every rate limit,
   daily meter and concurrency cap in the product silently multiplies by N on the day a second
   replica starts.
10. **Fetched syllabus documents are not fenced against prompt injection (1.17), and redirects skip
    the DNS check (5.4).** The discovery path takes a model-chosen URL, fetches a stranger's
    document, and feeds it to another model — the two weakest links in an otherwise careful chain.
