# The ledger: every law, and the words behind it

**The owner, 2026-09-11:** *"Please don't miss out anything we ever discuss. I might forget them in the
future but you shouldn't, because it's got to work the way we want it to work."*

So this file exists, and it is generated rather than remembered. Every law in `docs/` appears here with
the owner's own words where a law records them. A law absent from this table is a law nobody will find.

**The rule that keeps it true:** a decision made in conversation is written into a law file in the same
breath, that law gets a row here, and the work gets a row in `docs/NOW.md`. Three places, one action.
Nothing is 'remembered for later'. If a thing is decided and not written, it did not happen.
