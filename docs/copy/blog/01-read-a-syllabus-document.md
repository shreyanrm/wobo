**A syllabus is not current because a page says it is: it is current when you can name the document it came from, find the chapter on the page it cites, and see the date somebody last checked that the file was still there.**

Most of what a search engine returns for "syllabus" is a page about a syllabus rather than the syllabus. A chapter list gets typed up once, from a document that was correct that week, and then it sits there. Nothing on the page tells you which week that was, and nothing on the page moves when the board moves. That is not anybody's bad faith; it is just what happens to a copy of a document that has no date on it.

That matters more than it used to, because the boards have been moving. If your child's chapter list does not match the book in their bag, the list is usually the thing that is wrong.

Here is the check we run, in the order we run it.

## 1. Get to the board's own document

Start on the board's own site, not on a site about the board. In India the ones that matter are cbseacademic.nic.in for CBSE, ncert.nic.in for the prescribed textbooks, cisce.org for ICSE and ISC, and nios.ac.in for NIOS. State boards each have their own, and several of them will only serve the document to a browser, which is a real limit and worth knowing about before you spend an evening on it.

What you are looking for is a file, usually a PDF, that the board itself published. Not a summary of it. Not a blog post about it. The document.

## 2. Make it name its own year

A current syllabus says which academic year it is for, on its cover or in its header, in the board's own words. If the file does not say, you are holding something that cannot tell you whether it is this year's, and no amount of reading the chapter list will settle it.

This is the single fastest way to throw away a bad source. A chapter list with no year attached is a chapter list from an unknown year.

## 3. Check the document actually contains the chapter

Open the document and find the chapter. Not the chapter name in a contents page somewhere else: the chapter, in this file, on a page you can point at.

It sounds pedantic and it catches real errors. When we audited our own reading of the board documents, the checks that failed were almost all of this shape: a name that was in the document but not on the page we had cited, or a unit that the document numbered and we had not. One of our own class 11 mathematics files was short a chapter under Coordinate Geometry against the document's own numbering, and it is marked as provisional in our data because of exactly that. A chapter list that nobody has held against its own source is a chapter list nobody has checked.

## 4. Write down the day you read it

A document that was right in September can be replaced in November. The board does not send you a message when that happens. So the last check is the cheapest one: note the day you read the file, and note something that identifies the file itself, so that next term you can tell whether you are looking at the same bytes or at a new document with the same name.

We keep a hash of every document we read for exactly this. When we re-fetched all 41 of our source documents on 5 September 2026, every one of them came back identical to what the build had recorded, which is the only way to say "nothing changed" and mean it.

## What "current" still cannot tell you

A current document can still be read wrong, and this is the part nobody admits.

Our own class 10 science file passed every structural check and was still wrong about three topics, because a PDF's text layer indented a whole page and the first reading took that indent for the box the document uses to mark what is assessed only formatively. The checks asked whether every name was in the source. They could not ask whether we had understood what the source said about that name. It took a second reading, off the rendered pages rather than the text layer, to catch it.

So "verified" is a claim about the checks that passed, and it is worth saying which ones. It is not a claim of perfection, and anybody who offers you one should be asked what they checked.

## What we do with this

Every chapter page on this site carries the same four things, in plain sight: the official document the chapter came from, the page or section inside it, a hash of the bytes we read, and the day we read them. Where a board's document is one we are still checking, the page says so in those words rather than pretending.

It is not a feature anybody asks for. It is just the only honest way to publish somebody else's syllabus, and it is the thing you can use to check us the same way you would check anyone else.
